### 인수테스트 케이스

| ID | 제목                      | 입력                            | 출력/오류                    | 검증여부 | 설명     |
|----|-------------------------|-------------------------------|--------------------------|------|--------|
| 1  | 기본 예제                   | "//;\\n1"                     | "결과 : 1"                 | 예    |        |
| 2  | 기본 오류 예제                | "-1,2,3"                      | IllegalArgumentException | 예    |        |
| 3  | 빈값 입력                   | ""                            | "결과 : 0"                 |      | 요구사항문서 |
| 4  | 커스텀 구분자 선언 없는 입력        | "1,2,3"                       | "결과 : 6"                 |      | 요구사항문서 |
| 5  | 커스텀 구분자 선언 없는 다중 구분자 입력 | "1,2:3"                       | "결과 : 6"                 |      | 요구사항문서 |
| 6  | 커스텀 구분자 선언 있는 입력        | "//;\\n1;2;3"                 | "결과 : 6"                 |      | 요구사항문서 |
| 7  | 커스텀 구분자 및 기본 구분자 사용 입력  | "//;\\n1;2:3,4"               | "결과 : 10"                |      |        |
| 8  | 커스텀 구분자만 입력             | "//;\\n"                      | "결과 : 0"                 |      |        |

| 10 | 양수 이며 정수가 아닌 값 입력       | "A,2,3", "1,?,3", "1.5,2,3"   | IllegalArgumentException |      |        |
